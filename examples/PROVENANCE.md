# FLY HIGH: подлинные исторические OHLCV Robinhood

## Результат

Получены реальные ответы публичных API, без генерации свечей. Набор содержит COPY, HOPOUT и GPTHEIST: 200, 102 и 49 завершённых пятиминутных свечей соответственно. Для последних двух активов отдельный запрос `before_timestamp` перед самой ранней свечой вернул пустой список. Это ограничение доступной истории выбранного пула/провайдера, а не доказательство отсутствия иных сделок во всей сети.

| Актив | Свечей | Первая свеча UTC | Последняя свеча UTC |
|---|---:|---|---|
| COPY | 200 | 2026-09-13 13:20 | 2026-09-14 15:40 |
| HOPOUT | 102 | 2026-09-11 14:20 | 2026-09-14 13:55 |
| GPTHEIST | 49 | 2026-09-08 15:55 | 2026-09-13 22:45 |

## Файлы и воспроизводимость

- `canonical.json`: канонический набор для загрузки приложением.
- `provenance.json`: URL каждого сохранённого запроса, UTC-время начала/получения, HTTP-статус, относительный путь сырого тела ответа и его SHA-256.
- `raw/`: исходные JSON-ответы DexScreener и GeckoTerminal, включая проверку более ранней истории.
- Исходный сбор выполнен отдельными исследовательскими скриптами `collect.py` и `extend_verify.py`; эти скрипты не входят в публичный пакет. Сохранённые запросы, ответы и контрольные суммы входят полностью. Проверить конкретный запрос можно по URL из `provenance.json`; ответ провайдера со временем может измениться.
- Воспроизводимый офлайн replay публичного набора: `python3 -m flyhigh.import_history --input examples/canonical.json --symbol COPY --assumed-liquidity 10000 --output data/copy.report.json` из корня репозитория. Это реальные цены и явно гипотетическая ликвидность, а не историческое исполнение.

## Схема

```text
{
  source: string,
  collected_at: ISO8601 UTC,
  assets: [{
    symbol, name, token, pool, chain: "robinhood",
    timeframe: "5m", interval_seconds: 300,
    price_currency: "usd", timestamp_unit: "unix_seconds",
    bars: [{timestamp, open, high, low, close, volume_usd}],
    source_url, fetched_at, provider_meta,
    liquidity_snapshot: {usd, observed_at, historical: false, source_url},
    quality, older_history_probe?
  }]
}
```

`timestamp` — начало интервала в Unix-секундах UTC; O/H/L/C — USD за токен; `volume_usd` — объём торгов в USD по данным провайдера. Снимок ликвидности находится вне `bars`: `observed_at` означает время получения ответа нами, а не гарантированное время последнего обновления провайдером. Исторической ликвидности в наборе нет.

## Источники и выбор пулов

1. DexScreener: `https://api.dexscreener.com/latest/dex/tokens/{token}`. Проверены `chainId == robinhood` и совпадение адреса `baseToken`. Из соответствующих пулов выбран пул с максимальным текущим `liquidity.usd`; это выбор на момент сбора, потенциальный selection bias для исторического тестирования.
2. GeckoTerminal: `https://api.geckoterminal.com/api/v2/networks/robinhood/pools/{pool}/ohlcv/minute?aggregate=5&limit=250&currency=usd&token={token}&include_empty_intervals=false`. Адрес пула приведён к нижнему регистру. `meta.base.address` каждого ответа совпал с запрошенным токеном.
3. Для HOPOUT и GPTHEIST дополнительно использован `before_timestamp`, равный самой ранней доступной свече минус одна секунда; оба ответа HTTP 200 содержали ноль более ранних свечей.

Адреса токенов:
- COPY: `0xac79255f6f404eba14f316e8669d76573a2d7b1e`
- HOPOUT: `0x78f13072b0f6ebc7fd0b5359c9b4e09c6160cff8`
- GPTHEIST: `0xbabb2c60f2bc9dc39de6c37ba1de11491cae2242`

Это заданные мемкоины, не токенизированные акции и не USDG/WETH. WETH/ETH указан только как котируемый актив выбранных пулов.

## Нормализация и ограничения

- Выбраны до 200 последних завершённых свечей каждого актива; текущая свеча исключается относительно UTC-времени начала запроса. У COPY исключена одна незавершённая свеча; у остальных таких свечей в ответе не было.
- Метки времени отсортированы по возрастанию и дедуплицированы; проверены границы OHLC, неотрицательный объём и кратность timestamp 300 секундам.
- `include_empty_intervals=false`: промежутки без возвращённых свечей НЕ заполнены. Между соседними сохранёнными свечами COPY/HOPOUT/GPTHEIST обнаружено соответственно 55/63/25 разрывов длиннее пяти минут. Это не равномерная сетка. Не интерпретировать следующую запись как гарантированно следующие пять минут. Не синтезировать объём или ликвидность при ресемплинге.
- Данные принадлежат конкретному пулу, не являются агрегатом всех бирж/пулов токена. Возможны задержки, пересчёты и пропуски провайдера. Последняя свеча малоликвидного токена может существенно отставать от времени сбора.
- 200 свечей для каждого из трёх выбранных активов получить не удалось: HOPOUT и GPTHEIST имеют более короткую доступную непустую историю; синтетические свечи не добавлялись.
- Первичная проба через Python urllib получила HTTP 403; тот же публичный endpoint успешно прочитан через curl. Сбор проводился последовательно с паузами; сохранённые запросы успешны. URL и времена всех запросов основной процедуры находятся в `provenance.json`.
- Набор не подтверждает прибыльность стратегий. Он не содержит исторических спредов, глубины книги, газа, исполнимых котировок и исторической ликвидности; нельзя выдавать тестирование по этим свечам за реалистичную гарантию исполнения или доходности.
